How It Works & GitHub Hosting

OmniDrop is a completely client-side, zero-backend file and text sender that runs in any modern web browser (iOS Safari, Android Chrome, Windows, Mac, Linux).

🚀 How to Deploy on GitHub Pages:

  1. Create a new repository on GitHub (e.g. drop-sender).
  2. Upload this single index.html file to the root of the repo.
  3. Go to Settings > Pages in your GitHub repository.
  4. Under Build and deployment > Branch, select main and / (root), then click Save.
  5. Your site will be live at https://yourusername.github.io/drop-sender/ within seconds!

🔒 How Direct Transfer Works:

Transfers travel directly between devices using WebRTC DataChannels. Files never touch any intermediary storage or third-party cloud. For large files, chunked streaming ensures seamless transfer even on mobile browsers.

💡 Instant Mobile Pairing:

Click "Scan QR" at the top. Point your iPhone or Android phone camera at the screen to open the URL. Both devices will pair automatically!
