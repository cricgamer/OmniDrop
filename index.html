Why does it say "Connecting..."?

  • Both devices must have OmniDrop open at the same time. WebRTC does not queue messages when offline.
  • Ensure you typed the receiver's ID (not your own ID).
  • Testing across two tabs on the same computer? OmniDrop automatically syncs via local bus — look for the "Detected another tab" banner above!
  • On Mobile Cellular (4G/5G)? Mobile carriers sometimes use strict CGNAT firewalls. Try connecting both devices to the same Wi-Fi network.

How It Works & GitHub Hosting

OmniDrop is a completely client-side, zero-backend file and text sender that runs in any modern web browser (iOS Safari, Android Chrome, Windows, Mac, Linux).

🚀 How to Deploy on GitHub Pages:

  1. Create a new repository on GitHub (e.g. drop-sender).
  2. Upload this single index.html file to the root of the repo.
  3. Go to Settings > Pages in your GitHub repository.
  4. Under Build and deployment > Branch, select main and / (root), then click Save.
  5. Your site will be live at https://yourusername.github.io/drop-sender/ within seconds!

🔒 Direct Peer-to-Peer Transfer:

Files travel directly between devices using WebRTC DataChannels. Files never touch any server or cloud. For local testing across tabs or browsers on the same computer, an automatic high-speed bus handles transfers instantly.
