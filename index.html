How It Works & GitHub Hosting

OmniDrop uses a high-speed secure cloud relay over WebSockets that works through cellular firewalls, symmetric NAT, and home Wi-Fi networks worldwide.

🚀 Deploying on GitHub Pages:

  1. Create a new repository on GitHub (e.g. drop-sender).
  2. Upload this single index.html file to the root of the repo.
  3. Go to Settings > Pages in your GitHub repository.
  4. Under Build and deployment > Branch, select main and / (root), then click Save.
  5. Wait 1-2 minutes for GitHub Pages to deploy.
